# 烧录与控制步骤

> **前提**：已按 [01-硬件连接方案.md](01-硬件连接方案.md) 接好四根线（GPIO17→电机 RX、GPIO18←电机 TX、共地、电机独立供电 5–10V）。

---

## 1. 烧录固件

同一个工程目录，可以用 PlatformIO 编译，也可以用 Arduino IDE 编译，任选一种。**不需要 ESP-IDF 扩展**，这个固件用的是 Arduino 框架。

### 1.1 方式 A：VSCode + PlatformIO

1. VSCode 中选"文件 → 打开文件夹"，**直接选 `920demo/firmware/fzyt28_bringup` 这个目录**。PlatformIO 要求 `platformio.ini` 位于打开的文件夹根部。
2. 第一次打开时，PlatformIO 会自动下载 ESP32 平台和编译器，需要等几分钟（国内网络可能更久）。
3. 用 USB-C 数据线连上开发板。
4. 左下角状态栏：**✓** 编译，**→** 烧录，**🔌** 串口监视器。
5. 烧录失败时：按住 BOOT，按一下 RESET，松开 BOOT，再点 →。

### 1.2 方式 B：Arduino IDE

1. 安装 Arduino IDE 2.x，"开发板管理器"里安装 **Espressif Systems** 的 `esp32` 包（3.x）。国内下载慢可先在"首选项 → 附加开发板管理器网址"填乐鑫镜像：`https://jihulab.com/esp-mirror/espressif/arduino-esp32/-/raw/gh-pages/package_esp32_index_cn.json`
2. 打开 `fzyt28_bringup.ino`，"工具"菜单设置：

   | 选项 | 值 |
   |---|---|
   | 开发板 | ESP32S3 Dev Module |
   | USB CDC On Boot | **Enabled**（不选会编译报错） |
   | USB Mode | Hardware CDC and JTAG |
   | Flash Size | 8MB (64Mb) |
   | PSRAM | OPI PSRAM |

3. 点"上传"。

### 1.3 串口

板子插上后电脑出现两个 COM 口，**都能烧录、都能输命令**：
- **CH343 口**（设备管理器显示 `USB-Enhanced-SERIAL CH343`）= 固件里的 `Serial0`
- **原生 USB 口**（显示 `USB 串行设备`）= 固件里的 `Serial`。按 RESET 后会消失再出现的就是它。

串口监视器设 **115200**，行尾选"换行"。按 RESET 应看到：

```
==== FZYT-28 云台控制固件 / Waveshare ESP32-S3-DEV-KIT-N8R8 ====
电机串口: UART1  TX=GPIO17  RX=GPIO18  1000000 8N1
...
输入 help 查看命令
```

**LED 指示**：蓝 = 空闲；绿闪 = 收到电机数据；紫 = 透传模式；红 = 自检失败。

## 2. 控制电机（`st` 命令）

电机用飞特 SCS 协议，1 Mbps，出厂 ID = 2。`[id]` 省略时默认 2。

| 命令 | 作用 |
|---|---|
| `st ping [id]` | 探测电机，应显示 `ID 2 在线` |
| `st scan` | 扫描 ID 0–253，列出所有在线电机（约 15 秒） |
| `st pos [id]` | 读当前位置，显示计数和角度 |
| `st torque on\|off [id]` | 扭矩开/关。**出厂默认关，不开不会动** |
| `st move <角度> [id]` | 转到绝对角度 0–360，自动打开扭矩，并连续打印 1.5 秒的位置轨迹 |
| `st go <角度> [id]` | 转到绝对角度，只回一行结果（网页按钮用） |
| `st jog <±角度> [id]` | 相对当前位置转动，到 0°/360° 截止 |
| `st run <±度/秒> [id]` | **持续转动**。电机没有可用的速度寄存器，由 ESP32 每 20ms 推进目标位置实现匀速。调用方必须每 <700ms 重发一次当心跳，否则自动停；到边界自动停；上限 720°/s |
| `st stop` | 停止持续转动 |
| `st hold on\|off` | **上电保持**（默认开，存 NVS）：ESP32 开机就给电机开扭矩并锁在当前位置；之后每 2 秒检查，扭矩掉了（电机单独重启）自动重新锁定。`st torque off` 会临时松开，直到下一次运动命令或 `st torque on` |
| `st read <addr> <n> [id]` | 读寄存器。例 `st read 0x38 2` 读当前位置 |
| `st write <addr> <hex...> [id=N] [force]` | 写寄存器，16 位大端。例 `st write 0x2A 07 24` 目标位置 = 0x0724 = 1828。**0x16 默认拒绝写**（见下） |
| `st zero confirm [id]` | 把当前位置记为零位（写 EEPROM 0x16）。装配时对好机械零位后用一次 |

### 2.1 第一次测试

电机固定好、输出轴空载：

```
st ping           → ID 2 在线，错误码 0x00
st pos            → 当前位置 = 804 计数 = 70.7°（数值因电机而异）
st move 90        → 看到电机转，轨迹打印到 90° 附近
st move 0
st torque off     → 关扭矩，手能拧动
```

### 2.2 已知现象

- **上电有劲、推了回弹**：电机出厂上电扭矩关闭，改不了；固件默认开启"上电保持"（`st hold`），由 ESP32 在开机时打开扭矩，所以只要 ESP32 通电，电机就是锁住的。想要软的，`st torque off`（临时）或 `st hold off`（永久）。
- **写指令没有应答**是正常的（读指令才有）。固件在写后会自动读回确认。
- **到位精度**：±45° 移动 0.3 秒到位，正常情况下稳定后偏差 0–1 计数、读数不抖。早期几次测到到位后 ±30 计数的低频晃动，是间歇性的，怀疑是电机本体没固定在桌上跳动；测试前务必把电机固定好。
- **应答包第二个头字节是 `F5` 不是 `FF`**，固件已按此处理。
- **速度寄存器 0x2E 写入无效**，0x2C 能写但不起作用，目前都是全速运动（90° 约 0.3 秒到位）。
- **⚠ 0x16 不是 D 参数**：飞特表里 0x16 是位置环 D，但这台上写任何值都会把当前位置记为零位。固件的 `st write` 对 0x16 默认拒绝，需要时用 `st zero confirm`。
- **别乱调 0x15（P）**：实测从 77 降到 20 后到位晃动反而更大。
- **点动不跨 0°**：位置模式限位 0–4095，`st jog` 到 0° 或 359.9° 就截止，不会取模绕圈（早期版本会在 5° 按 −15° 时朝反方向转 345°，看起来像"发疯"，已修）。
- **靠近 0° 时有 20–30 计数的稳态误差**（`st go 5` 停在 27 左右），其他角度 0–1 计数。原因待查，可能是死区/最小启动力矩寄存器（0x18/0x1A）。

### 2.3 两个电机

出厂 ID 都是 2，接在同一条总线上会冲突。先**单独接**其中一个，改 ID：

```
st read 0x05 1               → 确认当前 ID = 2
st write 0x05 03             → 改成 3（写 EEPROM，可能需要先解锁，见下）
st ping 3
```

如果写 ID 后 `st ping 3` 没反应、`st ping 2` 仍在线，说明有 EEPROM 写保护。飞特标准是先写 0x37 = 0 解锁、改完写 0x37 = 1 上锁；FZYT-28 是否一样需要厂家确认，别盲试太多次。

## 2.3.1 舵机与灯

接线见 [01-硬件连接方案.md](01-硬件连接方案.md) 第 6 节。

| 命令 | 作用 |
|---|---|
| `servo <0~180> [ms]` | 舵机转到角度（GPIO4，50Hz）。默认按 300°/s 限速平滑过去，可指定用时，例 `servo 180 2000` |
| `servo us <500~2500> [ms]` | 直接给脉宽，用于试出舵机真实行程 |
| `servo speed <°/s>` | 改默认限速。限速能明显降低舵机启动的冲击电流 |
| `servo off` | 停止输出脉冲，普通舵机会松开 |
| `servo` | 显示当前脉宽/角度 |
| `led <0~100> [渐变ms]` | 灯亮度百分比（GPIO5，5kHz PWM，gamma 2.2），可选渐变时间。例 `led 100 2000` 两秒渐亮 |
| `led on` / `led off` | 全亮 / 关 |

网页上对应两个滑条和快捷按钮，拖动滑条时最多每 120ms 发一次命令。

**实测现象**：舵机接在开发板 5V 脚上时，每次大幅转动都会把 ESP32 的 USB 链路拉掉（ESP32 本身不重启）。舵机必须用独立 5V 电源。

## 2.4 网页 / 蓝牙控制

固件开机就在 BLE 广播，名字 `FZYT-28-xxxx`（后四位是板子蓝牙 MAC 的末两字节，`status` 命令能看到）。用的是 Nordic UART 服务：网页把文本命令写进 RX 特征，输出经 TX 特征通知回来，**命令和串口命令行完全一样**。

**使用**：用 **Chrome / Edge**（Windows、Mac、Android）打开 `920demo/webapp/index.html`，点"连接电机"，选 `FZYT-28-xxxx`。页面提供：**按住持续左/右转（速度 10–360°/s 可调）**、点动 ±1/5/15/45°、角度滑条、预设 0/90/180/270°、扭矩开关、实时位置（每 0.7 秒刷新，可关）、**舵机角度滑条、灯亮度滑条**、任意命令输入框和日志。

**限制**：
- iPhone 的 Safari 不支持 Web Bluetooth，iOS 上需要用 Bluefy 之类的浏览器，或改用 Wi-Fi 方案。
- 一次只能一个蓝牙客户端连接；断开后板子自动继续广播。
- 网页从本地文件打开即可（Chrome 允许 `file://` 使用 Web Bluetooth）；如果浏览器拒绝，在 `webapp` 目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000`。

网页按钮对应的命令：按住 = 每 300ms 发 `st run <±速度>`、松开 = `st stop`；`st jog <±角度>`（相对）、`st go <角度>`（绝对）、`st torque on|off`、`st pos`。

## 3. 调试工具

| 命令 | 用途 |
|---|---|
| `status` | 引脚、波特率、接收字节数和错误计数 |
| `baud <n>` | 切换电机串口波特率（电机是 1000000；旧云台协议是 115200） |
| `tx <hex...>` / `txsum <hex...>` | 原样发字节并抓回应 / 自动加 sum8 校验 |
| `listen [ms]` | 监听电机主动发出的数据 |
| `scan [ms]` | 逐个波特率监听（会自动排除上电毛刺） |
| `dump [clear]` | 打印板上缓存的最近 512 个接收字节（USB 掉线期间收到的也在） |
| `bridge` | USB 透传：上位机连原生 USB 口，CH343 口显示双向报文 |
| `selftest` | 短接 GPIO17-18 做收发自检 |
| `ptz <cmd>` / `jog` | 旧云台控制板的 `FC 80` 协议，**电机不认**，仅供对照 |

## 4. 向厂家要什么

协议格式已经破解，但寄存器表是厂家自定义的，标准飞特表里的电压、温度、电流、速度地址在这台上要么读 0 要么无应答。发给卖家：

> 你好，FZYT-28 我们已经用飞特 SCS 格式（1 Mbps，ID 2）读写通了，能转到指定位置。请提供：
> 1. **完整寄存器表**（地址、含义、单位、读写属性、EEPROM/RAM）
> 2. 目标速度、加速度、扭矩限制的寄存器地址
> 3. 当前电压、电流、温度、负载的地址
> 4. 修改 ID 和波特率的方法，是否需要解锁 EEPROM
> 5. PID 参数地址和推荐值（我们看到 0x15 = 77，0x16 写入后会记录当前位置，请确认 0x16 的含义）
> 6. 零位设置的正确流程，以及出厂零位怎么恢复（0x16 原值为 8）
> 7. 多圈模式的开启方法和位置表示
> 8. 上位机调试软件

拿到寄存器表后，在 `scs_protocol.h` 里补充地址，再给 `st move` 加速度参数。
