# 硬件连接方案：ESP32-S3 + FZYT-28

> **适用硬件**：微雪 ESP32-S3-DEV-KIT-N8R8，FANGZHOU FZYT-28 FOC 电机模块（原 on-device 自研云台用的电机，原来接在 RV1126B 的 UART7 上）。
> **依据**：微雪官方原理图（本目录下的 `ESP32-S3-DEV-KIT-N8R8-schematic.pdf`）、FZYT-28 规格书。出处见 [02-资料与出处.md](02-资料与出处.md)。

---

## 1. 接线总图

```
   电脑
    │ USB-C 数据线（必须是数据线，充电线没有数据脚）
    ▼
┌─────────────────────────────┐                     ┌──────────────────────┐
│ 微雪 ESP32-S3-DEV-KIT-N8R8   │                     │ FZYT-28              │
│                             │   ①  R1 1kΩ         │                      │
│ GPIO17 (TX)  ●──────────────┼──/\/\/──────────────┼──● PIN3  RX          │
│                             │   ②  R2 1kΩ         │                      │
│ GPIO18 (RX)  ●──────────────┼──/\/\/──────────────┼──● PIN4  TX          │
│                             │                     │                      │
│ GND          ●──────────────┼─────────┬───────────┼──● PIN1  GND         │
│                             │         │           │                      │
│ 5V 脚 ✗ 不要接电机            │         │  ┌────────┼──● PIN2  VDD         │
└─────────────────────────────┘         │  │        └──────────────────────┘
                                        │  │
                                        │  │  C1 470µF/16V 电解电容 + C2 100nF，
                                        │  │  焊在靠近电机插头的 VDD 与 GND 之间
                                        │  │
                              ┌─────────┴──┴────────┐
                              │ 电机电源             │
                              │  − (GND)   + (VDD)   │
                              │  5V / 2A 以上（直连） │
                              └──────────────────────┘
```

**三条原则：**

1. **ESP32 与电机必须共地**。没有公共地线，串口就不通。
2. **电机单独供电，不从开发板取电**。原因见第 3 节。
3. **TX 接 RX，RX 接 TX，要交叉接**。ESP32 的 TX 接电机的 RX。

## 2. 信号线

### 2.1 引脚对应表

| ESP32-S3 开发板 | 排针位置 | 串联电阻 | FZYT-28 |
|---|---|---|---|
| GPIO17（UART1 TX） | P1 第 9 脚 | 1kΩ | PIN3 RX |
| GPIO18（UART1 RX） | P1 第 10 脚 | 1kΩ（电机 TX 为 5V 时换成分压，见 2.3） | PIN4 TX（只控制转动时可不接） |
| GND | 丝印为 GND 的任一脚 | — | PIN1 GND |

**认丝印，不要数脚**。排针位置是按原理图数的，接线时以板上丝印 `17`、`18`、`GND` 为准。

### 2.2 为什么选 GPIO17 / 18

按官方原理图和乐鑫 GPIO 文档，下列引脚都不能用：

| GPIO | 被什么占用 |
|---|---|
| 19、20 | 原生 USB，经 CH334F 集线器接到 Type-C |
| 43、44 | UART0，接 CH343P 串口芯片 |
| 38 | 板载 WS2812B RGB 灯 |
| 35、36、37 | 模组内部的 Octal PSRAM（N8R8 的 R8） |
| 0、3、45、46 | 启动配置脚，上电时的电平会改变启动方式 |

GPIO17 和 18 不在上表中，而且在排针上相邻，适合接电机。

### 2.3 电平：大概率 3.3V，接 TX 前仍建议量一下

规格书没写串口电平，但有两条旁证：

- **电机 RX 能接 3.3V**：原来直连 RV1126B 的 UART7，是 3.3V TTL，而且能正常控制，所以 ESP32 的 GPIO17 可以直接驱动电机 RX。
- **电机 TX 的电平没有验证过**：原协议只发不收，RV1126B 的 UART7 接收计数一直是 0。可能是电机从不发数据，也可能原线束根本没接 TX。

只控制转动的话，**电机 TX 可以先不接**，只接 GPIO17 → PIN3 RX 和 GND，就没有电平风险。

要接 TX 时，ESP32-S3 的 IO **不耐 5V**，先按下面的步骤确认：

1. 电机单独上电，**不接 ESP32**。
2. 用万用表直流电压档，黑表笔接 PIN1 GND，红表笔接 PIN4 TX。
3. 按读数处理：

| 读数 | 含义 | 接法 |
|---|---|---|
| **约 3.3V** | 3.3V TTL | 按 2.1 直连，保留 1kΩ 串联电阻 |
| **约 5V** | 5V TTL | 电机 TX 经分压接 ESP32 RX：`电机TX → 1kΩ → GPIO18 → 2kΩ → GND`，GPIO18 得到约 3.3V。电机 RX 一侧，ESP32 输出 3.3V 不一定能被识别为高电平，建议改用 BSS138 双向电平转换模块 |
| **约 0V** | 未上电、TX 需要使能，或是反相电平 | 先不要接，找厂家确认 |

串联的 1kΩ 电阻用来限流保护。万一电平判断错了，或者上电顺序有问题，它能挡一下。115200 波特率下这个阻值不影响通信。

### 2.4 两个电机（上下 + 左右）的接法

原协议第 3 字节 `0x01` 管上下、`0x10` 管左右、`0x11` 管全部，推测是两个电机的 ID，共用一条串口。规格书也写了"多 ID 串口控制"。按这个推测，接法如下：

```
                       ┌──► 俯仰电机 PIN3 RX（ID 0x01）
GPIO17 ── 1kΩ ─────────┤
                       └──► 水平电机 PIN3 RX（ID 0x10）

GND ───────────────────────  两个电机的 PIN1 GND、电源负极，全部接在一起
```

- **一个 ESP32 TX 可以同时驱动两个电机的 RX**，这是正常的总线接法。
- **两个电机的 TX 不要直接并在一起接到 GPIO18**。两个推挽输出同时发数据会互相顶住。原协议用不到接收，TX 线都不接即可。
- **两个电机可以共用电源**。电源输出电流要 ≥ 2A（两个电机的堵转电流各 800mA）。
- **如果手上只有一个电机**：用 `jog` 分别试上下和左右，看它响应哪一组，就能知道它的 ID。详见 03 文档 2.3 节。

## 3. 电源

### 3.1 电机电源

| 参数（规格书） | 值 |
|---|---|
| 工作电压 | **5–10V** |
| 空载电流 | 75mA |
| 堵转电流 | 800mA |
| 最大功率 | 8W |

手上现有的电源是 **5V** 和 **12V**。

#### 方案 A（先用这个）：5V 电源直连电机

5V 在规格书 5–10V 的范围内，可以直接接，不需要任何转换，也没有调错电压的风险。

| 要求 | 原因 |
|---|---|
| **输出电流标称 ≥ 2A** | 一个电机堵转 800mA，两个就是 1.6A。电流不够时，电机一加速电压就会被拉低 |
| **电源线尽量短、尽量粗** | 5V 已经是下限，线上压降 0.3V 就会低于 5V。杜邦线又细又长，不适合走电源 |
| **470µF 电容必须加** | 补上电机加速瞬间的电流缺口（见 3.2） |

**怎么接**：
- **5V 适配器是 DC 头**：用 DC 母座转接线端子，接出 + 和 −。
- **是手机充电头**：用 USB 转接线端子板，接出 VBUS（+）和 GND（−）。

**5V 可能出现的问题**：电机能转，但比较软（扭矩和速度偏低）；转动启动或反向时，电机自己复位（又转一次自检）。出现这种情况就是电压被拉到 5V 以下了，改用方案 B。

#### 方案 B：12V 电源 + 降压模块，调到 7.5V

**12V 绝对不能直接接电机**，已经超过 10V 上限。必须先经过降压模块：

```
12V 电源 + ──► 降压模块 IN+      OUT+ ──► 电机 VDD
12V 电源 − ──► 降压模块 IN−      OUT− ──► 电机 GND（同时接 ESP32 GND）
```

| 项 | 要求 |
|---|---|
| **模块** | 可调降压模块，输出电流 ≥ 2A。常见的 LM2596（3A）或 MP1584（3A）模块都可以 |
| **输出电压** | **7.5V**，处于 5–10V 的中段 |

🔴 **调压步骤，一步都不能省**：
1. **先不接电机**，只给模块接上 12V 输入。
2. 用万用表量模块的 OUT+ 和 OUT−，旋转模块上的蓝色电位器，直到读数为 **7.5V**。新模块出厂时输出可能接近输入的 12V。
3. 断开 12V，再把电机接到 OUT 端。
4. 重新上电，再量一次电压，确认仍是 7.5V。

**❌ 不能用：**

- **12V 直连电机**：超过 10V 上限，会烧电机驱动。
- **开发板排针上的 5V 脚**：原理图显示这个脚接在 USB 的 VBUS 经 B5819WS 肖特基二极管之后，电流全部来自电脑 USB 口，通常只有 500–900mA。电机堵转或加速时电流冲到 800mA，会把 ESP32 拉到复位，严重时触发电脑 USB 口保护。

### 3.2 电容

在电机插头附近的 VDD 与 GND 之间并联两个电容：

- **470µF/16V 电解电容**（注意正负极）：电机急加速、急停时，线路上有电流冲击和反电动势，靠它吸收。
- **100nF 陶瓷电容**：滤除高频噪声。

### 3.3 ESP32 电源

用 USB-C 数据线接电脑，同时完成供电、烧录和串口调试。**不要**同时从 5V 脚和 3.3V 脚给板子供电。

### 3.4 上电顺序

1. 先插 ESP32 的 USB，确认电脑上出现两个 COM 口。
2. 再打开电机电源。
3. 断电时反过来：先关电机电源，再拔 USB。

这样可以避免电机先上电、ESP32 还没上电时，电机 TX 的电流经 GPIO 保护二极管倒灌进 ESP32。1kΩ 串联电阻对这种情况也有保护作用。

## 5. 第一次上电检查清单

按顺序做，每一步通过再做下一步：

- [ ] **ESP32 自检**：不接电机，用杜邦线短接 GPIO17 和 GPIO18，串口输入 `selftest`，结果应为"自检通过"。
- [ ] **接线复核**：GPIO17 是否接到电机 RX，是否共地，电源正负极有没有接反。
- [ ] **电源电压**：接电机前用万用表量一遍，确认在 5–10V 之间。**确认不是 12V 直连。**
- [ ] **（接电机 TX 时）量电平**：电机单独上电，量 PIN4 TX 的空闲电压（见 2.3）。
- [ ] **上电顺序**：先插 USB，再开电机电源。电机会自己转一次做自检，属正常现象。
- [ ] **转动测试**：输入 `st ping`（应显示 ID 2 在线），再输入 `st move 90`。
- [ ] 后续按 [03-烧录与控制步骤.md](03-烧录与控制步骤.md) 进行。

**电机固定**：测试时用 M2 螺丝把电机固定在台面或支架上（规格书外形图有 3-M2 安装孔），输出轴上不要装负载。FOC 电机响应很快，规格书写"转 60° 最快 3ms"，没固定的话一上电就可能甩出去。

## 6. 舵机与灯（2026-09-18 新增）

两路都用 ESP32 的硬件 PWM，引脚在排针 P1 上相邻：

| 功能 | ESP32 引脚 | 排针位置 | PWM |
|---|---|---|---|
| 舵机信号 | **GPIO4** | P1 第 3 脚（丝印 `4`） | 50 Hz，脉宽 500–2500 µs |
| 灯调光 | **GPIO5** | P1 第 4 脚（丝印 `5`） | 5 kHz，0–100% |

### 6.1 舵机

```
舵机 3 根线（常见配色）：
  棕/黑  GND     ──► ESP32 GND（并且与舵机电源负极共地）
  红     VCC     ──► 舵机电源 +（见下）
  橙/黄  信号    ──► ESP32 GPIO4
```

**舵机电源**：

| 舵机 | 电源 |
|---|---|
| 9g 小舵机（SG90 / MG90S）**仅测试** | 可以暂时接开发板排针的 **5V 脚**。它峰值电流 ~600mA，转动时可能让 ESP32 USB 掉线，正式用要换独立电源 |
| MG996R 等标准舵机，或正式使用 | **独立 5–6V 电源**（你的 5V/2A 适配器可以），负极与 ESP32 GND 接一起 |

**❌ 舵机不能接 8V 电机电源**：绝大多数舵机上限 6V（部分高压舵机 7.4V，看标注）。

ESP32 的 3.3V 信号舵机都能识别，不需要电平转换。舵机的 0°/180° 对应的脉宽因型号不同，默认按 500–2500 µs；转不到头或到头顶住有异响时，用 `servo us <µs>` 试出实际范围，改 `board_config.h` 里的 `SERVO_MIN_US / SERVO_MAX_US`。

### 6.2 灯

**方案 A：一个普通 LED（指示灯级别，≤20mA）**

```
GPIO5 ──► 330Ω 电阻 ──► LED 正极（长脚）    LED 负极（短脚）──► GND
```
ESP32 引脚最大 40mA，串 330Ω 时约 8mA，安全。

**方案 B：LED 灯带 / 大功率灯（12V 或 5V，电流大于 20mA）**

用一个 **MOSFET 模块**（淘宝"MOS 管模块 PWM 驱动"，IRF520 或 AOD4184 都行）做低边开关：

```
GPIO5  ──► 模块 SIG（或 PWM）
ESP32 GND ──► 模块 GND
灯电源 + ──► 灯 +
灯 −    ──► 模块 OUT−（漏极）
模块 VIN+/VIN− ──► 灯电源 +/−
```
灯电源负极必须和 ESP32 GND 共地。IRF520 是非逻辑电平管，3.3V 只能半开，灯不够亮或管子发热就换 **逻辑电平** 的 AOD4184 / IRLZ44N 模块。

固件对亮度做了 gamma 2.2 校正，滑条 50% 看起来才是一半亮。
